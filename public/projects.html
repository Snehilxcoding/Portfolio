AlfredWayne OS

Python · FastAPI · LLM APIs · NLP · Speech-to-Text · Text-to-Speech
Problem

Everyday digital tasks — scheduling, file management, app control — are scattered across separate tools and interfaces, and hands-free interaction with a personal system is mostly locked inside fixed voice-assistant ecosystems.

Approach

Built a modular AI assistant integrating LLM APIs for natural language understanding with Speech-to-Text and Text-to-Speech for voice interaction, backed by a FastAPI service layer. Designed with contextual memory so the assistant retains context across a conversation instead of treating every input in isolation.

Status

Actively in development — currently supports natural text/voice task automation on a modular architecture built to extend into productivity, customer support, and IoT-based use cases.

Heart Disease Predictor

Python · Pandas · NumPy · Scikit-learn · Matplotlib · Streamlit
Problem

Heart disease risk depends on dozens of interacting clinical variables — assessing it manually requires domain expertise that most people don't have easy access to.

Approach

Cleaned and preprocessed the UCI Heart Disease dataset (~1,000 patient records, 26 features after encoding), performed exploratory data analysis to identify the strongest risk indicators, then trained and evaluated a Logistic Regression model before wrapping it in a Streamlit interface so predictions are usable without touching any code.

Outcome

89.13% prediction accuracy, deployed as a live, publicly usable tool — not just a notebook.
